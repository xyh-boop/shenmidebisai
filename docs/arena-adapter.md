# 靶场适配清单

## 当前状态

**待验证。** 当前仓库已验证本地 CLI、离线扫描和 OpenAI-compatible 复核接口，但没有官方靶场的输入输出协议、容器/运行时说明、资源上限和网络策略。因此不得在提交材料中宣称已支持官方靶场或已完成闯关。

## 开始适配前必须确认

- 官方活动页面、适用年份和报名状态；
- Agent 的启动命令、输入格式、输出格式和超时规则；
- Python 版本、操作系统、依赖安装方式和可写目录；
- CPU、内存、磁盘、请求数、令牌和网络访问限制；
- 是否允许外部模型服务，凭据如何注入，源码是否允许出网；
- 成绩接口、提交截止时间和失败重试规则。

## 本地适配入口

```powershell
aegisflow doctor
aegisflow scan <靶场输入目录> --mode offline --format json --output .\artifacts\arena-report.json --fail-on none
```

若靶场要求 Agent 模式，应在获得授权后使用 `--model-config`，并保存固定输入、固定输出、运行日志、资源使用和失败降级记录。若靶场要求 stdin/stdout 或特定 JSON Schema，应新增一个适配器，不要在核心分析器中硬编码靶场协议。

外部 provider 的公网地址必须使用 HTTPS；明文 HTTP 仅在显式 `allow_insecure_http = true` 且目标为 loopback 时用于本机调试。外发源码只做尽力过滤，不能作为完整脱敏或秘密保护的证明。

## 验收证据

正式标记为“已适配”前，至少保存：一次等价模拟环境试跑、一次真实靶场试跑、输入输出样例、资源统计、超时/错误处理记录和结果截图。所有外部运行必须在授权范围内进行。

截至当前版本，独立留出集、授权真实案例、真实 provider 运行记录和官方靶场试跑均未取得；本地回归样例不能替代这些证据。
