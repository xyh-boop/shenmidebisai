## 模拟问题

```python
def export_order(request):
    order_name = request.args["name"]
    return open("/srv/exports/" + order_name).read()
```

AegisFlow 应记录：

- `source`：`request.args["name"]`，外部请求输入；
- `propagation`：字符串拼接形成动态路径；
- `sink`：`open`，读取文件系统路径；
- 规则：`AF-PATH-001` / `CWE-22`；
- 风险：用户输入未经过固定目录约束或安全名称收敛；
- 建议：解析路径并验证其仍位于固定目录内，或使用允许列表和安全 basename。
